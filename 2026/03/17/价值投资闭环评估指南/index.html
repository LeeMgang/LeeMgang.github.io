价值投资闭环评估指南

发表于 2026-03-17 分类于 投资学习笔记

在面对充满不确定性的现实世界时，大多数人习惯追求“绝对确定性”或依赖直觉。然而，真正顶级的决策者，往往将基本的概率论和组合数学内化为一种底层的思维模型——这就是查理·芒格在《穷查理宝典》中极力推崇的费马-帕斯卡系统。

这套系统不仅能用于人生重大选择，更能与企业基本面分析、贝叶斯定理和凯利公式结合，构建出一套机构级别的量化价值投资闭环。

一、 费马-帕斯卡系统与“期望效用”

这套系统运转的核心是“期望值”（Expected Value）的计算：

EV = Σ(Pi * Vi)

其中，Pi 代表某种结果发生的概率，Vi 代表这种结果带来的具体收益或损失。

在现实生活中，纯粹的金钱收益并不能完全代表价值。因此，我们需要将 Vi 转化为效用分数（Utility Score）。同样的客观结果，对不同人的主观影响是完全不同的（例如高薪但无个人时间，对不同人的效用截然不同）。

案例推演：去留决策的量化

假设面临合同到期，在“留下”与“离开”之间抉择。我们设定个人的效用权重为 5:3:2（物质回报 M : 时间自由 T : 成就感 A）。

专属效用公式为： U = 0.5 * M + 0.3 * T + 0.2 * A

选项 A：留在原单位（三种情景） * A1 平稳维持 (概率 70%)： M=6, T=8, A=4

效用：UA1 = 0.5 * 6 + 0.3 * 8 + 0.2 * 4 = 6.2 * A2 正向突破 (概率 10%)： M=8, T=5, A=8

效用：UA2 = 7.1 * A3 温水煮青蛙 (概率 20%)： M=4, T=8, A=2

效用：UA3 = 4.8

A 的总期望效用 (EUA)：

EUA = (0.70 * 6.2) + (0.10 * 7.1) + (0.20 * 4.8) = 6.01

选项 B：离开寻找新机遇（三种情景） * B1 成功跃升 (概率 30%)： M=9, T=3, A=9

效用：UB1 = 7.2 * B2 平滑过渡 (概率 40%)： M=6.5, T=5, A=5

效用：UB2 = 5.75 * B3 负向跌落 (概率 30%)： M=1, T=9, A=1

效用：UB3 = 3.4

B 的总期望效用 (EU_B)：

EUB = (0.30 * 7.2) + (0.40 * 5.75) + (0.30 * 3.4) = 5.48

结论： 尽管 B1 提供了最高单项效用（7.2分），但综合概率与个人权重后，EUA (6.01) > EUB (5.48)。理性计算击破了大脑“只盯最好结果”的幻觉。

二、 构建量化价值投资闭环

传统的自由现金流折现（DCF）模型存在“精确的错误”，微调折现率估值便天差地别。将基本面分析与概率系统融合，可以形成严密的交易闭环。

第一步：DCF + 费马-帕斯卡 = 期望内在价值 (EIV)

放弃单一目标价，设定三种平行情景： * 乐观情景 (V1)： 赋予基础概率 P1 * 基准情景 (V2)： 赋予基础概率 P2 * 悲观情景 (V3)： 赋予基础概率 P3

EIV = (P1 * V1) + (P2 * V2) + (P3 * V3)

决策：只有当当前股价大幅低于 EIV 时，才具备安全边际。

第二步：凯利公式 = 仓位管理

确定了赔率，用凯利公式（Kelly Criterion）决定下注比例，以在复利最大化与破产风险之间寻找平衡：

$$f* = p - (\frac{q} {b})$$

  • f*：建议仓位比例
  • p：胜率（乐观 + 基准概率）
  • q：败率（悲观概率）
  • b：盈亏比（(EIV - 股价) / (股价 - 悲观价值)）

注意：真实投资中为主观认知留足余地，通常采用“半凯利”（Half-Kelly）策略。

第三步：贝叶斯定理 = 动态更新系统

当新信息（如财报发布、突发事件）出现时，利用贝叶斯公式动态更新三种情景的概率：

P(A|B) = [P(B|A) * P(A)]/P(B)

  • P(A)：原定概率
  • P(B|A)：在某情景下，出现该新信息的似然度
  • P(A|B)：更新后的后验概率
  • P(B)：事件B发生的概率，采用全概率公式计算

$$P(B) = \sum_{i=1}^{n} (P(A_i) \times P(B|A_i))$$

展开后的形式为： P(B) = P(A1) × P(B|A1) + P(A2) × P(B|A2) + P(A3) × P(B|A3)

投资闭环实战沙盘

标的：Alpha 消费品（现价 40元）

  1. 初次评估 (算出 EIV 与建仓)：
    • 乐观 (V1=80元, P1=20%)
    • 基准 (V2=60元, P2=50%)
    • 悲观 (V3=30元, P3=30%)
    • EIV = 55元。存在 27% 安全边际。
    • 代入凯利公式得出 f* = 0.5（满凯利 50%）。执行半凯利，建仓 25%。
  2. 新变量出现 (贝叶斯更新)：
    • 突发季报：毛利率意外下降 3%。股价跌至 38元。
    • 评估似然度：乐观情景下发生概率 10%，基准 40%，悲观（陷入价格战）80%。
    • 计算后验概率：乐观骤降至 4.3%，基准 43.5%，悲观剧增至 52.2%。
  3. 闭环重估 (发出指令)：
    • 用新概率重新计算 EIV：跌至 45.2元。
    • 重新代入凯利公式：算得新 f* = -0.102。
    • 执行动作： 负数凯利值为强制指令，清仓卖出。

三、 概率的客观化锚定

“输入的是垃圾，输出的也是垃圾”。如果概率全是拍脑袋决定的，整个系统就会失效。必须建立客观锚定机制给概率“挤水分”：

  1. 寻找“基础概率”（Base Rates）： 放弃“内部视角”，查阅同类事件在历史上的大样本统计胜率。如果没有硬核证据，你的成功率只能等于行业平均倒闭率。
  2. 费米拆解法（Decomposition）： 将大黑盒拆成子事件。如果销量翻倍需要“产能跟上(80%) * 研发顺利(80%) * 宏观向好(80%)”，整体概率只有 51.2%。
  3. 向市场借“隐含概率”： 观察债券市场的息差或期权市场的隐含波动率（IV）。真金白银交易出来的价格，往往蕴含着极度客观的悲观/乐观预期。
  4. 设立“证伪清单”（Falsification Checklist）： 买入前写下“如果发生即宣告逻辑破产”的 3-5 个客观财务指标。一旦触发，系统强制将悲观概率调高至 80% 以上，斩断主观留恋。
